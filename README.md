# Лабораторная работа №1. Вариант 4. Множества

Шаблонный класс множества уникальных элементов на C++17.  
Тип элемента множества задаётся параметром шаблона `T`.

## Возможности

- Шаблонный класс `MySet<T>`: множество уникальных элементов на динамическом массиве.
- Поддержка типов элементов:
  - `int`
  - `float`
  - `std::string`
  - `std::pair<int, double>`
- Конструктор по умолчанию: пустое множество.
- Конструктор из массива значений (повторяющиеся значения пропускаются).
- Конструктор со случайным заполнением (количество значений, нижняя и верхняя границы); доступен только для числовых типов.
- Доступ к элементу по индексу через `operator[]` с проверкой границ.
- Операторы `+` (объединение) и `-` (разность) множеств.
- Операторы `+` и `+=` для добавления элемента, `-` и `-=` для удаления элемента.
- Метод `intersection()` — пересечение двух множеств.
- Метод `contains()` — проверка наличия элемента.
- Операторы сравнения на равенство и неравенство; вещественные числа сравниваются с точностью `EPS`.
- Оператор вывода в поток `std::ostream` без использования C-шных потоков.
- Метод `size()` — количество элементов.
- Интерактивное консольное меню для ввода и обработки множеств.

## Решаемая задача

**Вариант 4.** В заданном массиве найти все повторяющиеся числа.

Решение вынесено в функцию `findDuplicatesInArray()`, определённую вне класса.  
Используются два множества `MySet<int>`: в первом хранятся уже встреченные числа, во втором — найденные повторы.  
Если число уже есть в первом множестве, оно добавляется во второе, иначе в первое.

Пример: для массива `1 2 3 4 2 5 6 3 7 1 8 9 8` результат `{ 2 3 1 8 }`.

## Интерактивное меню

После автоматической демонстрации всех операторов программа предлагает выбрать тип элементов:

```text
Select type for interactive input:
  [1] int
  [2] float
  [3] string
  [0] exit
```

Затем нужно ввести два множества (количество элементов и сами элементы). Программа выводит объединение, разность и пересечение.  
Некорректный ввод приводит к исключению `std::invalid_argument`, которое обрабатывается и выводится через `std::cout`.

## Обработка ошибок

- `std::out_of_range` — выход за границы множества при обращении по индексу.
- `std::invalid_argument` — нулевой указатель на массив при ненулевом размере; неположительное количество в случайном конструкторе; нижняя граница больше верхней; некорректный ввод пользователя.
- `std::runtime_error` — в заданном диапазоне недостаточно уникальных значений для случайного заполнения.

## Особенности реализации

- Множество хранит элементы в динамическом массиве; при добавлении или удалении массив пересоздаётся нужного размера.
- Добавление уже существующего элемента ничего не меняет, удаление отсутствующего элемента тоже.
- Вещественные числа сравниваются с точностью `MySet<T>::EPS` (статическая константа, `1e-6`); для пар точность применяется к каждому компоненту.
- Для целых типов случайные значения генерируются через `std::uniform_int_distribution`, для вещественных — через `std::uniform_real_distribution`.
- Случайное заполнение для нечисловых типов запрещено на этапе компиляции (`static_assert`).
- Проверка типов выполняется на этапе компиляции через перегрузки `areEqual`, `if constexpr` и `static_assert`; `typeid` и `dynamic_cast` не используются.
- Конструкторы делегируют работу конструктору по умолчанию, поэтому при исключении в конструкторе выделенная память освобождается.
- Компиляторные предупреждения:
  - Clang/GCC: `-Wall -Wconversion -Wextra -Wpedantic`;
  - MSVC: `/W4`.
