# Лабораторная работа №1. Вариант 4. Множества

Шаблонный класс множества уникальных элементов на C++23.  
Тип элемента множества задаётся параметром шаблона `T`.

## Возможности

- Шаблонный класс `MySet<T>` уникальных элементов.
- Поддержка типов элементов, допускающих сравнение на равенство:
  - `int`
  - `float`
  - `std::string`
  - `std::pair<int, double>`
- Конструктор по умолчанию (создает пустое множество).
- Конструктор из массива значений.
- Конструктор со случайными значениями (количество элементов, нижняя и верхняя границы).
- Доступ к элементу по индексу через `operator[]` с проверкой границ.
- Операторы объединения (`+`) и разности (`-`) множеств.
- Операторы добавления (`+=`) и удаления (`-=`) элемента.
- Метод `intersection()` для пересечения двух множеств.
- Метод `contains()` для проверки наличия элемента.
- Операторы сравнения на равенство и неравенство (`==`, `!=`).
- Оператор вывода в поток `std::ostream` через `friend`-функцию.
- Интерактивное консольное меню для работы с множествами.

## Решаемая задача

**Вариант 4.** В заданном массиве найти все повторяющиеся числа.

Решение вынесено в отдельную функцию `findDuplicatesInArray()`. Функция использует два объекта `MySet<int>`: одно для запоминания уже встреченных чисел, второе для сбора дубликатов.

## Требования

- Компилятор с поддержкой C++17 (для `if constexpr` и `std::is_arithmetic_v`).
- Visual Studio 2022, GCC или Clang.
